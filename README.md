# ⚡ My Portfolio Website

A modern, responsive personal portfolio website built using **HTML, CSS, and JavaScript**, featuring a clean UI, animated background, and an interactive AI-style chatbot.

---

## 🌐 Live Demo
👉 https://dronamadhuri.github.io/portfolio/

---

## ✨ Features

- 🌈 Modern animated gradient background
- 🧊 Glassmorphism UI design
- 📱 Fully responsive layout (mobile-friendly)
- 💼 Projects showcase section
- 📄 Resume download option
- 🤖 Interactive AI-style chatbot
- 💬 Quick action chatbot buttons (About / Skills / Projects / Contact)
- ⚡ Smooth UI transitions and hover effects
- 🎯 Clean and minimal professional design

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox + Animations)
- JavaScript (Vanilla JS)

---

## 📁 Project Structure


portfolio/

## 🤖 Chatbot Features

The built-in chatbot can respond to:
